# UI/UX 全面見直し 評価記録（v1.1.0）

CLAUDE.md の「UI/UX 改修の意思決定ルール」に従い、項目ごとに実物のモックを作ってキャプチャ
（デスクトップ 1440×900 / モバイル 390×844）を確認し、採点した記録。

採点の観点：使いやすさ20 / わかりやすさ20 / 直感性15 / 汎用性15 / 視覚表現15 / 階層構造15（100点満点）

## 改修前の主な課題
- 右パネル（296px）に操作・視点・ライン構成の長文・解説がすべて並び、3D 表示領域を圧迫していた
- 統計は文字の表だけで、同期や測長の進み具合がひと目で分からなかった
- 3D ラベルが重なっていた（スタッカー／ランアウトコンベア、フライングシャー／測長ピンチロール）
- モバイルでは統計・工程チップ・ラベルが重なり、3D 表示は画面の約半分しかなかった

## 実装に反映した内容（A13 + B9 + C11）
- **ヘッダー**：1行に縮小。ライン構成・解説・操作方法は「ⓘ 構成・解説」のポップオーバーにまとめた
- **運転ドック**：運転／リセット、条件スライダー4本、再生速度、ルーパーを下部の1行に集約。
  モバイルではボトムシートになり、ハンドルで開閉する
- **視点コントロール**：3D の右上に、地図アプリのような縦並びのアイコン（全体／シャー／積載／上面／⚙表示設定）
- **機器ナビ**：3D の下部に番号付きの機器ボタンを並べ、クリックするとその機器へカメラが移動する
- **工程ステッパー**：4工程を並べ、現在の工程を強調。各工程の進捗をバーで表示し、測長値も工程①の中に表示
- **キャリッジ状態バッジ**：3D のキャリッジ上に「待機／加速○%／同期100%／戻り」を色付きで表示
- **生産カード**：ライン速度と、切断枚数・直前の切断長・搬出回数だけに絞った
- **機器ラベル**：番号と名称のピル。矩形どうしが重ならないように配置し、遠景では短縮名にする。
  ホバー中の機器（初期状態はシャー）は正式名で強調し、クリックするとその機器へカメラが移動する
- **その他**：Space キーで一時停止・再開。操作ヒントは8秒で消える。縦長画面では全体視点を引く。
  タブレット幅のブレークポイントを追加
